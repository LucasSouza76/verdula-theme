# Garden Guide 🌱

An **example** project to test the _Verdula_ theme in Markdown files.

[English](#installation) · [Português](#guia-do-jardim-)

## Installation

1. Clone the repository
2. Install the dependencies with `npm install`
3. Start the server:

```bash
npm run dev -- --port 3000
```

## Features

- Syntax highlighting for **more than 10 languages**
- Colors with _good contrast_ for long sessions
- [Official VS Code documentation](https://code.visualstudio.com/api)

> Tip: press `Cmd+K Cmd+T` to switch themes quickly.

| Color | Used for |
| --- | --- |
| Emerald | Functions |
| Jade | Types |
| Lime | Strings |
