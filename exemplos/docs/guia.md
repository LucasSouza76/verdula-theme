# Guia do Jardim 🌱

Um projeto **de exemplo** para testar o tema _Verdula_ em arquivos Markdown.

## Instalação

1. Clone o repositório
2. Instale as dependências com `npm install`
3. Rode o servidor:

```bash
npm run dev -- --porta 3000
```

## Recursos

- Destaque de sintaxe em **mais de 10 linguagens**
- Cores com _bom contraste_ para longas sessões
- [Documentação oficial do VS Code](https://code.visualstudio.com/api)

> Dica: use `Cmd+K Cmd+T` para trocar de tema rapidamente.

| Cor | Uso |
| --- | --- |
| Esmeralda | Funções |
| Jade | Tipos |
| Lima | Strings |
